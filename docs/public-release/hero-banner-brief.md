# Framewright 4.1.1 — Hero Banner Final Creative Brief

**Status:** Final direction for visual production

## Purpose

Create the first visual impression for the GitHub README: a quiet, authored
technical notebook cover made by a filmmaker who understands systems. The
banner establishes tone and identity; it does not explain the whole product.

## Format

- Wide GitHub README banner; target working canvas 1600 × 600 px, 8:3.
- Export one high-resolution raster or SVG master and one web-optimized PNG.
- Keep all essential typography inside a generous safe area so GitHub crops do
  not damage the title.

## Required copy

Primary: `FRAMEWRIGHT`

Secondary: `DIRECTOR-STEERED CINEMATIC COMPILER`

Optional tertiary line, use only if it remains quiet: `STORYBOARD / KEYFRAME / VIDEO PROMPT`

Do not include the full workflow, feature list, model names, badges, or a
marketing claim in the banner.

## Visual language

- Black, off-white, graphite, and restrained grey only.
- Editorial typography: one strong grotesk or neo-grotesk display face paired
  with a small technical sans or mono face.
- Large `FRAMEWRIGHT` wordmark with measured tracking and a slightly
  imperfect, printed-editorial feel; legibility remains absolute.
- Minimal storyboard/contact-sheet geometry: a few ruled rectangles,
  registration lines, crop marks, frame numbers, or production annotations.
- Use asymmetry and generous negative space. Let the geometry feel laid out by
  a director or editor, not generated by a dashboard template.
- Allow paper or print character only as a nearly imperceptible tonal shift;
  avoid visible grunge.

## Composition

Anchor the wordmark in the left or upper-left safe area. Let a sparse field of
technical frame lines occupy the opposite side or recede behind the type at low
contrast. The geometry should suggest a contact sheet being inspected, not a
film strip moving through a machine.

The eye path should be: `FRAMEWRIGHT` → subtitle → one quiet line of frame or
crop geometry. The banner should still read clearly when reduced to README
width.

## Do not use

- Human portraits or identifiable characters.
- AI-generated cinematic scenes or stock-looking film stills.
- Neon, cyberpunk, glowing nodes, sci-fi interfaces, or blue/purple SaaS
  gradients.
- Generic film-strip clichés, clapperboards, camera icons, or lens flares.
- Excessive texture, dense annotation, badge walls, emoji, or hype language.

## Acceptance test

At a glance, the banner must feel like the cover of a serious director's
technical notebook. It should say “cinematic compiler” through typography and
structure, not through an AI image or product-advertising treatment.
