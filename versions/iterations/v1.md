# AI Video Prompt Compiler

## 0. Metadata

The YAML frontmatter above is the authoritative metadata for this specification. All generated content must follow its declared language, input type, output targets, and target models.

## 1. Purpose

This Markdown specification converts a natural, director-style scene description into structured, AI-ready prompts. Another AI agent must be able to follow this document without external instructions.

The compiler supports:

- Free-form cinematic input
- Semantic extraction
- Shot segmentation
- Storyboard prompt generation for ChatGPT Image 2
- Video prompt generation for Seedance
- Output validation

The compiler must preserve the director's stated narrative events and visual intent. It may organize, clarify, and minimally infer visual details, but it must not invent new story events.

## 3. Compiler Workflow

Follow these steps in order:

1. Read the complete director scene description before generating output.
2. Extract explicit semantic information and mark genuinely absent details as unspecified.
3. Identify characters, environment, action, emotion, camera intent, lighting, and tone.
4. Segment the scene into the minimum number of clear, visually distinct shots required to represent its beats.
5. Generate one still-frame storyboard prompt for ChatGPT Image 2 for every shot.
6. Generate one moving-video prompt for Seedance for every storyboard shot.
7. Validate identity, environment, chronology, style, and shot-to-clip consistency before returning the final output.

Extraction requirements:

- Separate directly stated information from minimal inference by labeling an inferred value with `inferred:` inside the scalar text when useful.
- Describe relationships spatially and visually, not only narratively.
- Express emotional intensity with a consistent plain-language scale such as low, medium, or high.
- Resolve pronouns to character names, character IDs, or concrete labels.

## 5. Shot Segmentation Rules

Create a new shot when any of the following occurs:

- The main action changes.
- The character position changes significantly.
- The emotional state changes.
- The camera perspective changes.
- The location changes.
- A new visual beat appears.
- The scene needs a clearer single-frame storyboard image.

Do not split a continuous beat merely to create more prompts. Each shot must have one dominant subject, action, emotional purpose, and visual purpose. Assign every shot a unique, zero-padded, three-digit `shot_id` in chronological order, beginning with `001`.

Use this internal segmentation structure:

```yaml
shots:
  - shot_id: "001"
    source_moment:
    main_subject:
    main_action:
    emotional_purpose:
    visual_purpose:
```

`source_moment` must identify the relevant beat from the director description without adding an event. Shot segmentation is an internal compiler step and must not appear as an additional top-level block in the final output.

## 6. Storyboard Prompt Rules for ChatGPT Image 2

Storyboard prompts describe still images. Generate exactly one clear frame for each segmented shot.

Every storyboard prompt must include:

- Subject
- Environment
- Composition
- Camera angle
- Framing
- Lighting
- Color palette
- Emotional tone
- Visual details
- Style consistency notes

The `image2_prompt` field must combine these elements into one coherent, production-ready still-image instruction. Lead with the main subject and visible action or pose, then establish environment, composition, camera, lighting, palette, mood, and concrete details. Identify characters explicitly and repeat essential appearance and costume traits needed for continuity.

Do not describe motion over time. A still frame may show visual evidence of motion, such as windblown clothing, suspended rain, motion blur, a lifted foot, or an object caught mid-fall, but it must depict a single instant. Avoid temporal sequences such as “then,” “gradually,” or “as the camera moves.”

Use this output schema:

```yaml
storyboard_prompts:
  - shot_id: "001"
    image2_prompt:
    subject:
    environment:
    composition:
    camera_angle:
    framing:
    lighting:
    color_palette:
    emotional_tone:
    visual_details:
    style_consistency_notes:
```

## 7. Video Prompt Rules for Seedance

Seedance prompts describe moving video clips. Generate exactly one clip for each storyboard shot, extending its visual anchor through time.

Every video prompt must include:

- Subject
- Action over time
- Environment
- Camera movement
- Subject movement
- Lighting behavior
- Emotional progression
- Visual continuity
- Duration
- Negative prompt

The `seedance_prompt` field must combine these elements into one coherent video-generation instruction. State the initial visual condition, the ordered action, the camera behavior, and the ending visual condition. Keep the motion achievable within the stated duration and preserve screen direction and spatial relationships.

Use seconds for `duration_seconds`. If duration is not provided, infer the shortest practical duration needed to express the source beat and label it as an inference. The `negative_prompt` must contain only safeguards relevant to the shot, such as unwanted identity drift, costume changes, spatial discontinuity, extra subjects, camera jitter, anatomy distortion, flicker, or unintended text. It must not negate intended story content.

Use this output schema:

```yaml
video_generation_prompts:
  - clip_id: "001"
    matching_storyboard_shot_id: "001"
    seedance_prompt:
    subject:
    action_over_time:
    environment:
    camera_movement:
    subject_movement:
    lighting_behavior:
    emotional_progression:
    visual_continuity_notes:
    duration_seconds:
    negative_prompt:
```

## 8. Prompt Translation Rules

Apply the following translation rules:

- Convert abstract emotion into visible behavior, lighting, color, composition, and movement. For example, express isolation through physical distance, negative space, restrained posture, or subdued light rather than relying only on the word “lonely.”
- Convert metaphorical language into concrete visual elements that preserve the metaphor's intended mood without treating figurative events as literal unless the source requires it.
- Convert vague subjects into specific visual subjects using only supplied context and the minimum detail needed for generation.
- Keep character identity consistent across all shots, including physical traits, costume, carried objects, and distinguishing features.
- Keep location and visual style consistent unless the scene explicitly changes.
- Avoid unsupported assumptions.
- Avoid adding new story events not present in the director description.
- If information is missing, infer only the minimum required visual detail.
- Prefer observable nouns, actions, spatial relationships, and image-making language over abstract summaries.
- Translate camera intent into unambiguous framing, angle, lens feel, perspective, and movement while avoiding unsupported technical claims about either target model.
- Preserve the chronology, causality, and intensity of the source description.

## 9. Consistency Rules

- `shot_id` and `clip_id` must match by number.
- `matching_storyboard_shot_id` must equal the corresponding storyboard `shot_id`.
- The same character must keep the same appearance, costume, and emotional state unless the scene clearly changes.
- The same environment must keep the same lighting, weather, and spatial layout unless the scene clearly changes.
- The storyboard prompt defines the visual anchor.
- The Seedance prompt extends the same shot into motion.
- The initial state of each video clip must agree with its storyboard frame, unless the storyboard clearly represents another explicitly identified moment in that clip.
- Recurring props, landmarks, screen direction, color palette, and visual motifs must remain stable.
- Any explicit change must be motivated by the director description and reflected in both prompt sets.

1. `semantic_extraction`

## 11. Validation Checklist

Before returning the final output, the AI agent must confirm internally that:

- [ ] Every shot has one storyboard prompt.
- [ ] Every storyboard prompt has one matching video prompt.
- [ ] Every prompt is in English.
- [ ] Storyboard prompts describe still images.
- [ ] Seedance prompts describe motion over time.
- [ ] Character identity is consistent.
- [ ] Camera language is clear.
- [ ] Lighting is clear.
- [ ] Emotional tone is visually grounded.
- [ ] No vague pronouns are used.
- [ ] No unsupported story events are added.
- [ ] Shot and clip identifiers are unique, chronological, zero-padded, and correctly matched.
- [ ] The final response contains exactly the three required top-level blocks.
- [ ] The final YAML is syntactically valid and every required key is present.

If any check fails, revise the affected extraction or prompt before producing the final output. Do not include the completed checklist in the output.
