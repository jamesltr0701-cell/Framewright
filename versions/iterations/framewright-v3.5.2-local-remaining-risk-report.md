# Framewright v3.5.2-local 剩余风险

## R01 — Lark native export unavailable

The current Lark Prompt Guide was verified as the correct document, modified August 12, and its directory plus visible passages were read. A native full export could not be obtained. Exact special-syntax glyphs therefore remain `snapshot-qualified` from the reconciled PDF rather than freshly export-qualified.

Mitigation: special syntax activates only for an explicit scope and carries its evidence grade. Re-freeze the native export before stable promotion if it becomes available.

## R02 — deterministic tests are not model evidence

The 53 fixtures validate representation, routing and guards only. They do not measure actual Seedance adherence, stability, audio continuity, backward extension quality, typography, or cost.

Mitigation: when the user's platform exposes Seedance 2.5, run separately authorized field tests by route and keep evidence scene-local.

## R03 — stable-range recommendations may evolve

50 total assets and per-media limits are current hard limits. Subject counts, 5-10 second reference-video guidance, under-20-second edit guidance and 15-panel storyboard guidance are recommendations, not bans.

Mitigation: they produce warnings and never silently split, withhold, or change an approved GU / board.

## R04 — Prompt syntax varies by surface

The `@` mention remains an operator action / UI chip, while `.txt` stores a surrogate. API bindings may use provider fields rather than literal prompt text.

Mitigation: Run Card owns the binding map; clean Prompt owns only active model-facing semantics.

## R05 — numeric timing and exact text remain probabilistic

Integer-second timestamps improve progression control but are not frame-accurate edit points. Prompt text alone cannot guarantee exact typography, formula rendering or sign layout.

Mitigation: use prepared assets, locked references or post-production when those properties are critical.

## Promotion boundary

This remains a local experimental candidate. Desktop, GitHub, README and release snapshots remain unchanged. Promotion requires a separate approval and must re-run three-location synchronization checks at that time.
