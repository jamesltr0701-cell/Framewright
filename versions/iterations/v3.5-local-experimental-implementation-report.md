## 4. Implemented architecture

The candidate now follows this dependency map without creating a second pipeline:

```text
User intent and explicit locks
-> Adaptive Semantic Interrogation
-> Production Spine.intent_ledger
-> Causal State Completion
-> Blocking Readiness
-> Visual Strategy compatibility
-> Committed Shot / Phase Spine
-> active stage artifact
-> Semantic Preflight
-> clean saved prompt + assistant-facing Intent Delta
```

Authority remains:

```text
latest explicit user decision
> approved intent_ledger entry
> derived Production Spine fields
> committed shot, panel, and stage views
> runtime adapter serialization
```
