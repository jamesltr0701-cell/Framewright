## 4. Protected-rule regression

以下基线机制均保留：

- director-steered identity、one workflow / one entry、三个 stage、exactly one active stage；
- Unified Director Intake、Intake Hard Stop、三种 director mode、三种 scene grammar；
- explicit director locks、单一 Production Spine、start/end/geography/object-state continuity；
- Entity Token Isolation、monochrome line-only storyboard、board/panel 16:9、exterior masthead；
- drawable frozen instant、visual sentence、Sequence Shuffle Test、no arbitrary camera variety；
- production-critical camera path contract、cinematography carriers、Style Survival、Surface Fidelity；
- count/entity locks、Compactness、Compression Safety、Stale-Negative、GU Feasibility；
- no auto split/merge、semantic timing、continuous phases are not cuts、Final Payoff Hold、Performance Vitality；
- environmental ambience + synchronized SFX + no music default；
- reference lifecycle、Silent Reference Exclusion、Runtime Cleanliness、saved output paths、validation-before-save；
- prompt-only default，只有 C06 的一次初始 Storyboard board 为窄例外。

未发现 adapter 覆盖 core、Seedance route 改变 director mode、grid 反向决定 panel count、board pressure 自动拆 GU 或 Storyboard 自动进入 Video runtime 的规则。

## 7. Native mention serialization trace

- UI：`@` 触发 material selection；缩略图、filename、chip、index 只是 surface display。
- TXT：保存 `@Image 1` / `@Video 1` / `@Audio 1` surrogate，无法保存 interactive chip。
- API：使用 provider asset field / ID，保持同一 stable role 和 authority。
- Run Card：负责 surrogate-to-file / `material_key` 映射。
- Prompt：无歧义单主体可直接以 mention 作主语；多主体使用最短限定。

三种 surface 未被混成一个永久 handle，且 UI 操作说明未进入 clean prompt。PASS。
