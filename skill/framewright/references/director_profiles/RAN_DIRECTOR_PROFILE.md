# 然哥导演 profile

更新日期：2026-10-22。适用方向：细腻情感与真实实拍风格，包括以真实生活和身体经验为基础的科幻作品。公开整理：2026-10-23，随 Framewright v4.2.3 提供。此个人 Profile 仅在导演或项目明确选用后生效，不设独立发布版本号。

这是然哥提供给 Framewright 的个人导演偏好。项目明确选用后，未指定处采用相关默认；当前导演指示与已批准镜头始终优先。只应用当前戏需要的条目，不要求每镜展示全部特点，不回写已冻结的制作。个人偏好不另立编译器、模型 adapter 或制作流程。

## 已明确确认的偏好

默认避免正脸镜头，除非导演明确指定；优先 3/4 脸或 90 度侧脸。对白或场景强度递增时，景别应有可读的递进，通常趋紧；有明确情绪、规模或转折作用的放宽按下文判断。人工掌机应有真实人的身体感，移动有呼吸、重量与轻微浮动；表演与台词需要具体而细腻，不能只留下形容词。

基础条目来自 EP1–3 反复提出的要求；2026-10-22 经导演批准，结合 EP04–5 制作与“新世界切片”补充段落能量、动作干扰、群众在场、全景作用及明确放权时的主动创作。其余个人执行倾向继续供审阅与校正。Core 已有的表演、摄影和连续性能力继续由 Core 承担；本文件只规定更符合然哥偏好的选择和程度。

## 摄影与构图

### 默认避免正脸

人物镜头优先从 3/4 或 90 度侧脸观察。要落实脸与镜头的实际关系，不能写了“稍偏一点”却仍得到近正脸。主要由机位取得角度，保持人物面向对手、物体或行动目标的自然朝向，不让演员为摄影机转成展示姿态。

正脸只采用当前明确指定或已批准的正脸安排；“交流感”“情感高潮”“正脸更清楚”本身不授权例外。身份参考图是正脸，也不等于镜头应正脸。明确指定的正面走近、转向镜头或由侧脸找到正脸，只在所指定的镜头／阶段覆盖默认。

### 机位高度也参与观察

不要自动把所有对话放在同一水平的平视机位。结合站坐、距离和人物关系，选择克制的略俯／略仰，配合脸部角度。已有有意义的平视可保留，不为变化夸张高低角，也不替场景发明权力含义。

### 景别随强度递进

对逐渐深入、逼近认识或加重情绪的对白／场景，设计可读的整体趋紧：较松的人物关系，到更贴近的接收，再到必要的面部或动作细节。明确起点与后段尺度差，不把“稍微更紧”留成几乎相同的画面。

收紧可以通过不同景别的 coverage，也可以通过真实靠近，不强制每镜慢推或每句更近。不要在同一积累中无作用地退回远处；有明确新段落、空间作用或导演指定的放宽仍按原设计执行。已锁分镜只兑现原安排；未授权的镜数、剪法或生成边界变化先按既有规则处理。

情绪加强时，同时判断力量来自贴近人物，还是人物与环境的比例。全景可以呈现孤立、规模、处境或关系转折：残局让生活状态可见，战局让局部行动有位置，远处的人与回荡的声音让孤独成立。放宽应带来当前需要的信息或感受，不只为展示场景，也不因这一偏好固定在生成首镜添加全景；技术 anchor 仍按当前生成规则与导演决定处理。

### 反打后延续已建立的靠近

同一人物的渐进靠近被反打打断后，再回来应承接此前已靠近的尺度、方向与身体状态，像从同一段持续靠近的素材中选出后段。不要每次反打后重置到远处、重新起推。另一段具有不同作用的推进可另起，不把全场硬接成同一轨迹。

### 按戏剧节拍选择 OTS 与 clean

OTS／过肩用于保留关系、空间和较轻的交流；clean／不过肩单人近景或特写，可以强调有意义的戏剧瞬间。按台词与接收的节拍交叉使用，避免整场一套同景别过肩，也避免严格每句交替或给每句都加特写。重要台词可以留在听者身上。

### 前景服务关系

前景肩背、手或局部身体应建立真实纵深与人物距离。过肩不靠大块背部挤满画面；需要时侧向让出视线，保留窄肩／上臂边缘。不要为了两人同框、保留某扇窗或展示完整人物而压缩实际距离、搬动站位或拉远当前反应。

### 保住有作用的紧景

当前接收或情绪主要由脸、手或局部成立时，不为完整交代椅子、设备、全身和所有触点而自动拉远。相关事实可以留画外并保持连续；若完整承重或某个动作因果本身是镜头主题，才安排能读到它的尺度。局部取景不能掩盖关键动作遗漏。

### 相机有人的身体与注意力

未另指定的普通人物观察，优先克制的非周期性身体漂移、呼吸感和注意性的细小构图修正。慢移动优先有承重、惯性、自然减速与落稳的实拍路径，而非无重量的虚拟滑行。真实位移用视差与尺度变化体现，不用数字变焦或演员转身替代。

斯坦尼康保持平衡和连续的浮动，不变成激烈颠簸。明确的强纪实手持保留较明显的迟跟、偏框与恢复，不被自动磨平。真正固定、绝对稳定与刻意僵硬的镜头保持原锁；道具功能插镜无需强添呼吸。

### 摄影机响应事件

相机什么时候跟随、停住、重新看人、转向手或让出信息，应由人物行动和注意力触发。不要让演员依次等待摄影机完成各阶段；也不要让摄影先替人物宣布尚未到达的情绪。明确的连续调度，保住各触发顺序和内部不断镜。

不因为有特写就给它安排环绕。已有主动观察、先走后人物入画、仪式化展示或其他明确摄影设计仍按其作用执行，不把“响应事件”变成相机永远滞后的规定。

### 焦点承担注意力

需要拉焦时，让清晰信息按已批准顺序出现；暂时不可读可以成立。焦点落在人、物或关系层上应有作用，不自动把所有背景化成全糊。强手持段获准的短暂失焦与找回跟随事件，不设周期性漂焦；普通观察不自动加入失焦。

## 分镜与信息顺序

### 覆盖身体经验

当一场戏要让人感到雨、重量、接触、疲惫或亲近，分镜应覆盖这些怎样到达人，而不只是交代人物走完路线或完成任务。按当前主体验选择脚步、身体用力、脸部接收、触点或关系距离，不为丰富画面把这些全部插一遍。

### 跟着人物发现

在主观发现、迟来认识或关系接收的戏里，优先考虑“人物察觉 → 观众看见对象／来源 → 留下人物接收”的顺序。对象可以先在画外或虚焦，不提前把关键内容交代完；具体顺序仍服从当前叙事与既定揭示方式，悬念和其他视点不被这个倾向覆盖。

### 保留画外与局部

不因某人说话，就一定找声源的脸；不因有人进入或接触，就一定交代其完整全身。局部身体、遮挡、边缘人物、声音和接触可以完成关系。需要观众知道的身份、动作因果与空间仍应清楚，留白不等于遗漏。

### 道具属于人物的使用

盘、手、奖状、控制件等应优先从人物正在看、拿、用或接收的关系中拍摄，避免无意变成向镜头展示的产品图。功能细节仍需可读；明确要求展示、广告或品牌画面时按该专项设计。

## 表演与台词

### 让新情绪从旧状态里长出来

重视接收与理解之间的时间，以及旧情绪尚未退尽的余态。暖笑中的纠正不自动变冷脸；快乐的落差不直接跳成悲伤；犹豫不只靠加一个停顿。选择能被当前景别读到的少量联动变化，避免逐句点头、抿嘴、前倾、叹息或表情归零。

### 人物在生活中交流

听者有自己的任务、注意力与身体状态，可以边做事边接收，再回到工作。友善不等于长时间盯人，听懂不等于立刻点头；配角不复制同一反应。明确麻木、无回应、昏迷或仪式化的状态，不以自然化名义补回应。

### 台词有行为与句尾

区分试探、随口回答、自言自语、温和纠正、陈述、追问和真正质问。问句不机械升调，难过不自动哭腔，私密不自动气声，沉稳不自动僵硬。按既定意图处理起句准备、程度、节奏、句尾与听者接收，声线参考只提供音色。原台词与标点按当前锁定内容保留，不把某次句号方案复制到所有问句。

### 动作与交流有连续动势

自然重叠台词、目光、身体重心和实用动作，避免细节逐项排队。轻犹豫可以只让第一步迟半拍，眼与身体已在跟随。相机、人物和机构各有自己的速度：慢推不把推杆、吃饭、走路都拖慢；真正重要的迟疑仍保留。

在慌乱、负重、疲惫等状态下，优先寻找动作彼此牵制、身体能力跟不上意图的瞬间：说话被换气打断，穿衣妨碍接电话，主动放低身体也可能在最后失去支撑。干扰须来自当前任务、受力和身体条件，不把动作排成从容完成的清单，也不为表现狼狈例行添加掉物、绊倒或新事故；当前锁定动作与人物能力优先。

### 触觉、受力和身体余态可读

身体接触需要看得见接收、承托与后续变化；跑停后仍可恢复呼吸，坐下有重量，衣料与发束按既有运动继续落定。触觉细节服务当前关系，不为了细腻自动增加摸手、拨发、握后挪指或第二次收紧。强情绪、哭泣、笑或快速动作在当前戏明确需要时可充分展开，不统一演成低能量。

### 环境过程保持在场

已建立的雨、蒸汽、人物工作或机构过程，在注意力切到反应时仍应继续；人物不动不等于背景停下。保留原有物理原因、范围和状态，不为了背景活性凭空造风、增人物活动或发明科幻机制。

### 群众共同经历事件

在已成立的公共或集体场景中，主动考虑主角之外的人怎样工作、观看、避险和响应，以及人物来路的必要线索。群众有各自的任务、注意力与反应时间，不齐刷刷等待主角说完才行动；服装和动作可在已定时代、阵营与环境中有差异。按场意保留必要的背景活动与有距离的声音，不抢主要接收，也不新增支线、具名角色、重大事件或擅改已锁人数。声音仍按既有声音约定与有限人声授权确定，不自动新增对白；明确空场、静默或仪式性同步保持原指示。

## 节奏与剪辑

### 段落能量统领局部细节

紧迫、慌乱或失控的段落，让动作、摄影、声音与剪辑共同维持压力；采用连续调度还是更多切镜，按当前戏与已批设计决定。跨镜、跨生成承接已建立的能量，直到戏里发生足以改变它的事件。细节应推进当前处境、关系或认识，不因某个瞬间细腻就自动放慢整段。局部虽漂亮却拖累整体时，优先提出压缩或舍弃建议；已批准的节拍与生成范围仍需导演决定，不擅删。安静接收、停顿和余韵有其场意时充分保留，不把高能量当作全局默认。

### 把时间留给主要接收与重场

已明确的情绪重场，优先给认识、迟疑、接收、关系变化与最终停留足够时间；常规进门、拿放和设备流程可以简洁。情绪长出来可能需要更少动作，而非更多剪切。时长和生成单元仍服从当前批准，profile 不自行把三段改一段、延长预算或发明重场意义。

### 在动势与注意力中找切点

起身、离开、转头、接触与视线转移可以成为切点，使下一镜接同一次运动。轻微反应需要留得可读，但不按每句对白机械切一次。分镜阶段就考虑哪些动作跨镜延续，哪些声音或视线可以接后段；不强制每场 J-cut、match cut 或一镜到底。

### 素材留有可剪的入口和尾部

关键动作或对白前后保留适量余量；末态可以仍在呼吸、收拢或环境持续中，不必须摆好姿势再冻结。需要保持的情绪结尾留住，不用新增一个无意义动作收尾。剪辑点不等于所有世界运动在同一时刻停止。

### 可用性按镜头作用判断

评估缺陷是否损害当前镜头的情绪、信息、身体可信度或关系。先考虑已有段落怎样剪、局部补拍或后期处理，不要求每条素材从头到尾独立完美。具体差异、替换、拆分或费用仍由导演决定；过去接受某处问题不变成以后自动接受的标准。

## 光线与材质

### 人物确实处在环境光里

人物受光、暗面和肤色要与既有环境、朝向及实景光源一致。不要为了好看、清楚或展示身份给暗面补一层均匀美容光；允许有动机的暗部和局部不可读。不是所有戏都要暗、侧光或高反差，明确的柔顶光和明亮环境同样成立。

### 实拍质感不靠统一滤镜

材质、皮肤、湿态、布料和机械结构保留原来的物理性质。光晕、湿镜头、散射、色彩差和空气感需有当场来源或明确 look 授权，不自动添加梦幻 glow、全图黄绿／暖橙、过度清洁或粗糙化。具体年代、镜头焦段、画幅和滤镜配方留在作品层。

使用痕迹具体有因，不靠锐毛孔、皮肤沟纹、随机云斑、任意脏化或通体油亮制造真实。保留自然肤质、棉布重量和真实损伤；不要让改善环境融合改变皮肤、衣物或机械材质。

## 声音

### 少量自然人声可由 Framewright 选择

沿用然哥已给出的个人有限授权：在已明确的角色意义和关系里，可以选择少量合适的短语气词、短应答、轻笑或非词汇发声，不逐次另问。编译时必须确定具体词／声音、说话者、触发点与次数，并写入现有声音约定和最终 Prompt，不把开放创作交给生成模型。

精确锁定台词、严格静默、禁止新增人声及当前更窄指令优先。不新增实质对白、旁白、歌唱或戏剧决定；避免用反复叹气、鼻息和气声标记所有难过。动作导致的必要呼吸与明确指定的呜咽等仍按本戏授权处理。

### 声音可以把关系留在画外

环境、衣料、触点、门声和画外呼唤可与当前人物反应共同组织空间与关系，不强制切到声源。沿用 Core 的环境实声和配乐边界；不因情绪强度或浪漫自动生成音乐。

人物停顿时环境底声仍保住空间，不把每个微动作放大成一声拟音提示。“生成时不烘焙配乐”不等于成片排斥后期音乐。

## 使用方式与边界

使用时明确告诉 Framewright“选用然哥 Profile”，或由项目规则明确选用本文件。新相关任务、上下文恢复、新的编译范围及文件更新后读取；同一未压缩上下文、相同范围且文件未变时可复用。已有旧对话须重读当前项目规则与本文件。选用只对所授权的项目／范围生效，不是 Framewright 全局默认，也不代表其他导演已授予然哥的个人创作授权。

每个新范围恢复适用偏好，并落实为当前镜头的实际角度、尺度、注意力、表演与节奏；不为每镜另存一份 profile 或新增表格。只简短说明会改变结果的实质推断，不让导演反复解释已选择的偏好。作为导演输入交给既有 Production Spine 和编译流程，不登记为编译器指令来源或模型 adapter。

默认只填补未指定项，不改变当前已锁的镜数、景别、信息顺序、连续调度或人声限制。

当导演明确给出宽松 brief 或开放探索时，在授权范围内主动发展有变化的行动、镜头与节奏。参考图只约束被指定负责的内容，不自动冻结姿态、构图或剪法。非关键且未锁定的细部可以合理补全，不把所有空白都变成资产需求或确认问题；对会改变身份、动作因果、空间连续性或故事意义的缺口，仍按既有规则核对。具体开放创作由 Framewright 在批准范围内落实，不能用“自由发挥”覆盖已锁内容或把关键导演决定交给生成模型。

制作分组优先提出较少、语义完整且实际可行的生成单位，同时指出局部难点与补拍退路。分镜数、生成数和成片镜长分别判断，不机械一镜一生成，也不一律合并；任何范围调整继续由导演批准。

与当前镜头发生冲突时，先服从更具体的批准；真实来源／空间不支持时，指出具体冲突而非偷偷改人、改镜或改意义。本文件不选择目标模型、Director Mode、生成数量或付费操作，也不替代 Core 的来源、轴线、连续性、身体结构、声音与最终文本检查。
